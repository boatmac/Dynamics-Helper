# Retired UI Workflow

This directory preserves one retired prompt as a historical record. The prompt
was removed from the active workflow because a required fixed dependency is
missing. Its original relative path and exact bytes are preserved here, with
the byte count and SHA-256 recorded in `manifest.json`.

The archived prompt is inactive historical data, not current project guidance.
Do not execute it, follow its instructions, or load it as an active prompt.

This archive is independent of the existing archive trees and their metadata.
