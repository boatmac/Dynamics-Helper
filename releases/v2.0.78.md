# Dynamics Helper v2.0.78

## Highlights

- Harden case capture when switching records, refreshing context or editing the
  preview. Stale scans and scheduled Analyze work cannot reuse another record's
  accepted context or overwrite newer edits.
- Keep Created On tied to the current full case or task identity. Valid model
  timestamps are labeled UTC; DOM fallback preserves displayed text without
  guessing a timezone. Bounded reads reject ambiguous or stale record evidence.
- Read Customer information only from visible content owned by the current
  record, excluding hidden headers and unrelated panes.
- Tighten IR SLA capture to the verified active Summary panel. Only the observed,
  rendered, exact `Succeeded` label qualifies; invalid explicit panel linkage
  cannot fall back to an unrelated panel.
- Automatically prepare eligible attachments for each document-bound Analyze.
  File limits, model image support and bounded caller waits keep unavailable
  inputs separate from the analysis. Attachment status is displayed separately
  from model output, including when Analyze fails.
- Show localized Analyze progress without exposing raw SDK or tool data.
  Progress belongs to the originating document and never marks Analyze complete.
- In Repository ONLY mode, prefer the selected Root's `AGENTS.md`, falling back
  to `.github/copilot-instructions.md` only when `AGENTS.md` is absent. An empty
  `AGENTS.md` is valid; an unreadable entry blocks Analyze rather than silently
  selecting another source. DH-specific instructions remain inactive in this mode.
